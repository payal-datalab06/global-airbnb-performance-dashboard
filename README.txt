Airbnb dataset samples for GitHub

These are random, reproducible samples drawn from the original Airbnb datasets. They are intended for preview and portfolio demonstration only, not as the complete source data.
Listings_sample.csv: 5,000 sampled listing rows.
Reviews_sample.csv: 10,000 sampled review rows.
The original dashboard may have been built using the full datasets; results computed from these samples may differ.
Original dataset source: user-provided Airbnb Data archive. Check source terms/licensing before redistribution.
